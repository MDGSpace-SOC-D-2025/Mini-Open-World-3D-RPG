MINI3DRPG

A third-person Unreal Engine 5 game prototype featuring exploration and custom mechanics.

----------------------------------------

-> REQUIREMENTS

- Unreal Engine 5.7
- Windows 10/11
- Visual Studio 2022 (for C++ projects)

---------------------------------------

-> PROJECT SETUP

Due to GitHub size limits the **Content folder is hosted externally**

### Download Content here:
https://drive.google.com/drive/folders/1nKykv7p_P7Q1rKIMGFpEjok8nCDo3TSi?usp=sharing

--------------------------------------

-> Follow these steps

1. Clone this repository:
git clone https://github.com/MDGSpace-SOC-D-2025/Mini-Open-World-3D-RPG

2. Download Content.zip from Drive.

3. Extract it into project root so you get:

MINI3DRPG/
 - Content/
 - Config/
 - Source/
 - etc...

4. Right-click .uproject → Generate Visual Studio files (if not already there)

5. Open project.
