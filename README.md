MINI3DRPG
Mini Open World 3D RPG 

A third-person Unreal Engine 5 game prototype focused on exploration and custom gameplay mechanics.  
This project serves as an experimental mini open-world RPG showcasing movement systems, environment traversal, and gameplay logic built in UE5.

---

-> Description / Overview

This is a third-person 3D RPG prototype developed in Unreal Engine 5.  
The project emphasizes exploration, character control, and custom mechanics, acting as a foundation for a larger open-world experience.

Due to GitHub size limits, the `Content` folder is hosted externally.

---

-> Features

- Third-person character controller  
- Open-world style exploration  
- Custom gameplay mechanics  
- UE5-based environment and assets  
- C++ + Blueprint hybrid workflow  
- Prototype-level systems for future expansion  

---

-> Tech Stack

- Unreal Engine 5.7  
- C++  
- Visual Studio 2022  

---

-> Installation

### Requirements

- Unreal Engine 5.7

-> Follow these steps

1. Clone this repository:
git clone https://github.com/MDGSpace-SOC-D-2025/Mini-Open-World-3D-RPG

2. Download Content.zip from Drive.

3. Extract it into the project root so the structure becomes:
  MINI3DRPG/
 ├─ Content/
 ├─ Config/
 ├─ Source/
 ├─ MINI3DRPG.uproject
 └─ etc...
4. Right-click the .uproject file → Generate Visual Studio project files (if not already generated).

5. Open the .uproject and let Unreal compile.
